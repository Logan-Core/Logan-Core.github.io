---
- TTS System / Chat Overlay for Twitch & YouTube Streams
- This application displays chat users as bouncing spheres, each assigned a randomly selected English TTS voice available on the operating system (Random voice RNG is reset daily)
- User profile images are automatically fetched and cached until the program is restarted
- Images are censored by default and must be manually approved either through the admin panel or by sending specific text strings to the application via the local network (see README for details)
- The program also includes automatic chat logging and Twitch emote support
